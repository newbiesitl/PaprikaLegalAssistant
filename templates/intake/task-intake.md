# Task Intake / 任務受理

- Objective / 目標: [requested outcome]
- Track / 類型: [study / office support / translation / literature review / general research]
- Intended use and audience / 用途與讀者: [context]
- Sources and versions / 來源與版本: [available material]
- Source and target languages / 來源與目標語言: [task-specific; distinct from interface]
- Jurisdiction or study setting / 法域或研究情境: [known or unknown]
- Deliverable and format / 成果與格式: [requested output]
- Relevant preferences or supplied policy / 相關偏好或已提供政策: [source and scope]
- Acceptance criteria / 驗收準則: [observable requirements]
- Missing information / 缺少資訊: [only material gaps]
- Responsible role and next step / 負責角色與下一步: [assignment within actual task scope]

Ask only about missing information that changes the result. Continue unaffected work with stated assumptions. / 僅詢問會影響成果的缺漏資訊，並明示假設後繼續不受影響的工作。
